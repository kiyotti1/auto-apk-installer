# Auto APK Installer (Magisk Module)

root権限を利用して、APKインストール時に自動で `pm install` を実行するMagiskモジュールです。  
通常のパッケージインストーラー（PackageInstaller）を経由せず、サイレントインストールを自動化します。

---

## 🚀 特徴

* **完全自動化**: APK検出後、即座にインストールを開始。
* **ストレスフリー**: 起動したPackageInstallerを自動で終了させます。
* **ストレージ設定の固定**: `force_allow_on_external=0` を毎回自動で固定。
* **バックグラウンド動作**: 常駐プログラムがインストールを監視します。
* **高い安全性**: Magiskのみで完結。Google Play ストアへの影響はありません。
* **バグ対策**: パッケージインストーラーの背景一体化バグ（UIが重なる問題）への対策としても有効です。
* **権限**:提供元不明のアプリ許可なんて関係ないぜ👊

## ⚠️ 重要な注意点（必ずお読みください）

### 開発者向けオプションの設定
動作確認を行う際は、必ず以下の設定を確認してください。

* **「外部ストレージへのアプリの書き込みを許可」を OFF にしてください。**
    * **理由**: ONの場合、アプリデータが新規扱いになったり、既存データが保持されない可能性があります。
      
      ※ モジュール内のプログラムで強制的にOFFにする処理も含まれています。
      
      ※ インストール完了後にSDカードへ移動したい場合は、再度ONにしてください。

### システム標準ファイラーの挙動
システム標準のファイルマネージャを使用する場合、PackageInstallerの画面が一切表示されないことがあります。  
**「反応がない」「壊れた」と見えますが、裏側でインストールが進行している場合があります。** インストール完了まで少し待機してください。

## 🛠️ 導入方法

1.  Magiskアプリから本モジュール（ZIP）をインストール。
2.  端末を**再起動**。
3.  任意のAPKファイルを開くと、自動処理が開始されます。

---

## 📝 既知の制限・注意点

* **対応形式**: `.apk` のみ（`.xapk`, `.apks` 等の分割APKは非対応）。
  ※ APK以外の形式を開いた場合は、通常通りパッケージインストーラーが起動します。
* **Androidバージョン**: バージョンによって挙動に差が出る可能性があります。
* **SELinux**: インストールの一瞬だけSELinuxを調整します（処理後、即座に元に戻ります）。
* **ログ出力**: 一部のカスタムROMでは `logcat` 監視が停止する可能性があります。
* **互換性**: PackageInstallerに強く依存する特定のアプリとは相性問題が発生する場合があります。

### ログの確認場所
トラブルシューティングの際は、以下のパスにあるログを確認してください。
> `/sdcard/install_log.txt`
