# Auto APK Installer

root権限を利用して、APKインストール時に自動で pm install を実行するMagiskモジュールです。

通常のパッケージインストーラーを経由せず、自動インストールを行います。

---

特徴

APK検出後に自動インストール

PackageInstallerを自動終了

force_allow_on_external=0 を毎回固定

バックグラウンド常駐

Magiskのみで動作

Play ストアには何も影響しません。ご安心ください

おそらく、あのパッケージインストーラー背景一体化バグの対策にもなると思います。

重要な注意

開発者向けオプションについて

動作確認する場合は、

「外部ストレージへのアプリの書き込みを許可」

を OFF にしてください。

ONだと、アプリデータが新規扱いになったり、 既存データが保持されない場合があります。

一応プログラムにもoffにするプログラムを入れています。

SDカードに保存したい場合は、インストール後再びONにしてください

---

システム標準ファイラーについて

システム標準のファイルマネージャでは、 本当にPackageInstaller画面が出ない場合があります。

「反応してない」「壊れた」と勘違いしやすいので注意してください。

インストール自体は裏で進んでいる場合があります、ログを確認してみてください。

既知の注意点

xapk,apks等は非対応です。apkのみ可能です。
apk以外の場合はしっかり、パッケージインストーラーが開かれますのでご安心ください。

Androidバージョンによって挙動差あり

SELinux を一瞬いじります。（インストール後戻ります）

一部ROMではlogcat監視が止まる可能性あり

PackageInstaller依存アプリでは相性問題の可能性あり
